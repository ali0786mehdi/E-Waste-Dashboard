## 📖 Overview

This repository contains the deliverables for my **E-Waste Management course assignment**. 
The project provides a comprehensive, data-driven assessment of the e-waste management infrastructure across 10 major districts in Maharashtra. It analyzes 78,300 MT of generated e-waste against the deployment of 80 collection centres and 65 authorized recyclers.

Our analysis reveals a strong correlation between Tier-1 city generation (Mumbai and Pune account for the vast majority) and infrastructure deployment, while highlighting the need for increased awareness drives in Developing districts like Kolhapur and Amravati.

> **Prepared By:** Ali Mehdi Mirza (Roll No: 24102C0015)  
> **Primary Data Source:** `Maharashtra_EWaste_Dashboard_Dataset.xlsx`

## 🗂️ Project Deliverables

I have developed two core deliverables based on the provided dataset. You can open the HTML files directly in any modern web browser or visit the deployed site.

### 1. 📄 Academic Project Report (`report.html`)
An analytical report designed for academic submission and policy review.
*   **Executive Summary:** High-level overview of Maharashtra's e-waste infrastructure.
*   **District-wise Analysis:** Detailed breakdown of Generation vs. Infrastructure capacity.
*   **Key Findings:** Synthesized insights highlighting the dominance of Tier-1 cities.
*   **Recommendations:** Actionable steps for Developing districts.

### 2. 📊 Interactive Dashboard (`dashboard.html`)
A modern, dark-themed interactive data visualization dashboard.
*   **Dynamic Visuals:** Built with Chart.js to map out generation volumes vs. recycler capacities across all 10 districts.
*   **Quick Insights:** Color-coded status badges highlight the performance of each district instantly.
